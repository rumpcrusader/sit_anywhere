# Sit Anywhere

Desktop Anon can sit down on the ground wherever he is standing.

- **Z** sits him down.
- **Z** again stands him up.
- Moving (WASD) or **Q** also stands him up.

It works on any floor: indoors, outdoors, on paths and on terrain. Furniture seats and AnonPony
are unchanged. The mod is desktop-only; nothing happens in a headset.

## Install

Copy `sit_anywhere-1.0.0.pck` from the release into the game's mods folder
(Settings → Mods → Open mods folder) and enable it in **Settings → Mods**.

## Compatibility

Made for Home: Equestria `0.3.0-maredev`. Desktop only.
