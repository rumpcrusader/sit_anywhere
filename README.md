# Sit Anywhere

Desktop Anon can sit down on the ground wherever he is standing.

- **Z** sits him down.
- **WASD** shuffles him along the floor while he is sitting.
- **Z** again or **Q** stands him up.
- **E** while seated stands him up too, as it does on any furniture seat.

He stops at walls, furniture and ledges. It works on any floor: indoors, outdoors, on paths and
on terrain. Furniture seats and AnonPony are unchanged. The mod is desktop-only; nothing happens
in a headset.

## Install

Copy `sit_anywhere-1.1.0.pck` from the release into the game's mods folder
(Settings → Mods → Open mods folder) and enable it in **Settings → Mods**.

## Compatibility

Made for Home: Equestria `0.3.0-maredev`. Desktop only.
